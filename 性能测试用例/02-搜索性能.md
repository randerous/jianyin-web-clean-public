# 02 搜索性能

## 目标

验证搜索请求、结果渲染、竞态处理、分页交互是否足够快。

## 测试方法

记录：

- `search_submit_ms`：按 Enter 到发起请求。
- `first_result_ms`：按 Enter 到第一个结果可见。
- `search_play_ms`：点击结果到音频进度增长。
- `race_settle_ms`：慢快请求竞态到最终结果稳定。

## 用例

| ID | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| PERF-SEARCH-01 | 普通搜索 | 输入常见关键词并搜索 | 首个结果 `< 3s` |
| PERF-SEARCH-02 | 搜索播放 | 点击首个结果 | 进度增长 `< 2s` |
| PERF-SEARCH-03 | 连续搜索 | 快速搜索 A、B、C | 最终显示 C，不卡顿 |
| PERF-SEARCH-04 | 慢快竞态 | mock A 延迟 2s，B 立即返回 | B 不被 A 覆盖 |
| PERF-SEARCH-05 | 大结果渲染 | mock 60 条结果 | 列表渲染 `< 1s`，滚动不卡 |
| PERF-SEARCH-06 | 搜索失败 | mock 500 | `< 3s` 内显示 toast |

## 记录字段

```text
keyword:
result_count:
first_result_ms:
search_play_ms:
race_settle_ms:
long_tasks:
console_errors:
```

## 通过标准

- 普通搜索 P95 `< 4s`。
- 搜索播放 P95 `< 3s`。
- 搜索竞态结果正确，不出现旧结果闪回。
