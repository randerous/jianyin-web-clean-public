# 01 首页与歌单加载性能

## 目标

验证首页推荐、刷新、推荐歌单打开是否存在明显慢点。

## 测试方法

建议使用 Playwright，记录 `performance.now()`：

- `home_visible_ms`：打开页面到“今日推荐”可见。
- `first_playlist_visible_ms`：打开页面到第一个推荐歌单可见。
- `refresh_done_ms`：点击刷新到推荐列表稳定。
- `playlist_detail_ms`：点击推荐歌单到详情首屏歌曲可见。

## 用例

| ID | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| PERF-HOME-01 | 首页冷打开 | 新 browser context 打开首页 | “今日推荐” `< 2s` 可见 |
| PERF-HOME-02 | 首页刷新 | 点击刷新按钮，计时到首个推荐歌单可点击 | `< 3s`，不白屏 |
| PERF-HOME-03 | 推荐歌单详情 | 点击第一个推荐歌单 | 详情首屏 `< 3s` 可见 |
| PERF-HOME-04 | 连续刷新 | 连续点击刷新 5 次，每次间隔 1s | 无卡死，P95 `< 4s` |
| PERF-HOME-05 | 接口慢响应 | mock 首页接口延迟 2s | UI 有 loading，不误判空结果 |
| PERF-HOME-06 | 接口失败 | mock 首页接口 500 | `< 3s` 内显示错误，不白屏 |

## 记录字段

```text
home_visible_ms:
first_playlist_visible_ms:
refresh_done_ms:
playlist_detail_ms:
network_requests:
console_errors:
```

## 通过标准

- P95 推荐歌单打开 `< 4s`。
- 刷新不阻塞页面导航。
- 预热请求不能阻塞详情首屏展示。
