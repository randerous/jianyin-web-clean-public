# 04 下载与本地缓存性能

## 目标

验证下载写入 IndexedDB、本地缓存播放、下载管理打开和删除测试数据的性能。

## 安全要求

- 删除测试必须使用隔离 browser context。
- 测试 key 必须是新建 key，例如 `download_flac_flac_perf_时间戳`。
- 禁止删除真实下载记录。

## 用例

| ID | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| PERF-DL-01 | 单首下载 | 下载一首测试歌 | downloadHistory `< 2s` 更新 |
| PERF-DL-02 | IDB 写入 | 下载后读取 IDB key | key `< 2s` 出现 |
| PERF-DL-03 | 本地播放 | 下载管理点击本地歌 | `blob:` 播放 `< 1s` |
| PERF-DL-04 | 下载管理打开 | 下载记录 50 条 | 列表 `< 1s` 可见 |
| PERF-DL-05 | 下载记录 200 条 | mock 200 条 downloadHistory | 页面无明显卡顿 |
| PERF-DL-06 | 删除测试下载 | 删除测试 key | `< 1s` 从 UI 和 IDB 消失 |

## 记录字段

```text
download_count:
download_history_update_ms:
idb_key_visible_ms:
local_play_ms:
manager_open_ms:
delete_ms:
```

## 通过标准

- 50 条下载记录打开 P95 `< 1.5s`。
- 本地 blob 播放 P95 `< 1.5s`。
- 删除只影响测试 key。
