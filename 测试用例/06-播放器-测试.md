# 06 播放器测试

## 环境

- 使用 mock 音频 `/assets/full-song-65s.wav` 或真实可播放歌曲。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| PLAYER-01 | 播放 | 点击歌曲 | `audio.paused=false`，进度增长 |
| PLAYER-02 | 暂停/恢复 | 点击暂停再播放 | 状态和图标一致 |
| PLAYER-03 | 进度拖动 | 拖到中段 | `currentTime` 接近目标 |
| PLAYER-04 | 下一首 | 多首队列点击下一首 | 当前曲目变化 |
| PLAYER-05 | 上一首 | 点击上一首 | 当前曲目回退 |
| PLAYER-06 | 播放模式 | 顺序/单曲/随机切换 | UI 状态正确 |
| PLAYER-07 | 倍速 | 设置 0.5/1/1.5/2x | `playbackRate` 正确 |
| PLAYER-08 | 歌词 | 自动歌词或导入 LRC | 歌词显示，当前行高亮 |
| PLAYER-09 | EQ 与淡入淡出共存 | 开启 EQ（如 Hi-Fi）播放，切换歌曲 | 切歌淡入淡出正常，EQ 持续生效、无爆音/拉链噪声 |
| PLAYER-10 | EQ 播放中切换 | 播放中设置里切换预设/强度 | 增益平滑过渡（0.02s），不断音、不重启播放 |
| PLAYER-11 | EQ 旁路恢复 | Hi-Fi → 原声 → Hi-Fi | 原声时零处理（直连），恢复后链重新接入、声音正常 |

## 通过标准

- 播放控制 1 秒内有 UI 状态变化。
- 播放失败必须有 toast，不能无反馈。
