# 08 下载管理测试

## 环境

- 删除类测试必须使用隔离 browser context。
- 测试 key 示例：`download_flac_flac_999001`。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| DL-01 | 下载歌曲 | 搜索结果点击下载 | downloadHistory 增加，IDB 出现 `download_...` |
| DL-02 | 入口数量 | 我的页查看下载管理 | 显示正确数量和“全部 N” |
| DL-03 | 本地播放 | 下载管理点击已下载歌 | `audio.currentSrc` 是 `blob:` |
| DL-04 | 删除按钮 | 查看下载管理每行 | 有“删除下载”按钮 |
| DL-05 | 单首删除 | 删除隔离测试歌曲 | downloadHistory 变 0，测试 IDB key 消失 |
| DL-06 | 无缓存历史删除 | 仅有 downloadHistory、无 blob | 记录删除，不报错 |
| DL-07 | 刷新保持 | 下载后刷新页面 | 记录仍在，本地缓存可播 |

## 通过标准

- 不允许对真实下载记录执行删除测试。
- 删除只影响测试 key。
