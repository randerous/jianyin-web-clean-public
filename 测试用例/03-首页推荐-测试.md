# 03 首页推荐测试

## 环境

- 桌面端：`http://127.0.0.1:5188/`
- 可用 mock 首页接口，也可走真实接口做性能 smoke。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| HOME-01 | 推荐加载 | 打开首页等待推荐区 | 推荐歌单/歌曲可见 |
| HOME-02 | 刷新推荐 | 点击刷新按钮 | 内容刷新或保持可用，无卡死 |
| HOME-03 | 首页直接播放 | 点击首页歌曲 | `audio.paused=false`，`currentTime>0` |
| HOME-04 | 推荐歌单打开 | 点击首页推荐歌单 | 3 秒内打开详情首屏 |
| HOME-05 | 预热不阻塞 | 监控歌单打开与预热请求 | 详情先显示，预热后台执行 |
| HOME-06 | 接口失败 | mock 首页接口 500 | 显示可读错误，不白屏 |

## 通过标准

- 首屏加载有反馈。
- 推荐歌单打开不能长时间空白。
