# 05 歌单详情测试

## 环境

- 使用本地测试歌单或 mock 推荐歌单。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| PL-01 | 打开歌单 | 点击“我的”里的歌单 | 详情弹层打开，数量正确 |
| PL-02 | 歌单内搜索 | 详情搜索框输入歌名 | 只显示匹配歌曲 |
| PL-03 | 播放全部 | 点击“播放全部” | 第一首播放，队列建立 |
| PL-04 | 单曲播放 | 点击任意歌曲行 | 当前曲目切到该歌曲 |
| PL-05 | 下一首/上一首 | 播放后点击控制按钮 | 曲目切换正确，不卡顿 |
| PL-06 | 全选可见 | 搜索后点击全选可见 | 只选择当前可见结果 |
| PL-07 | 加入队列 | 选中歌曲加入队列 | toast 正确，队列增加 |
| PL-08 | 反转排序 | 已保存歌单点击反转 | 顺序反转，刷新后保持 |

## 通过标准

- 歌单详情打开 3 秒内有可交互内容。
- 歌单内动作不能影响其他歌单数据。
