# 02 移动端布局与顶部留白测试

## 环境

- 视口：`390x844`
- 目标：验证播放后不会触发旧的大播放器布局。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| LAYOUT-01 | 播放后切页 | 播放一首歌后点击“我的” | 顶部无 1/4 空白 |
| LAYOUT-02 | root class | 读取 `.app-shell.className` | 有 `has-mini-player`，没有 `has-live-player` |
| LAYOUT-03 | 数值检查 | 读取 `.workspace` paddingTop、`.topbar h1` top | paddingTop `< 80px`，h1 top `< 130px` |
| LAYOUT-04 | 底部遮挡 | 播放时观察 mini player 和底栏 | 播放器不遮挡底部导航 |
| LAYOUT-05 | toast 层级 | 播放时触发 toast | toast 可见且不被播放器挡住 |

## 通过标准

- 播放状态下页面仍从顶部正常开始。
- 旧 class `has-live-player` 不应再出现在 `.app-shell`。
