# 11 设置测试

## 环境

- 打开“我的”页，点击设置按钮。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| SET-01 | 播放音质 | 切换标准/极高/无损/Hi-Res/母带 | localStorage 保存，请求带对应质量 |
| SET-02 | 下载音质 | 切换后下载歌曲 | 下载 resolve 使用所选质量 |
| SET-03 | 主题 | 切换浅色/深色 | DOM theme 生效，刷新保持 |
| SET-04 | 歌词源 | 网络/内嵌切换 | 配置保存，行为符合选择 |
| SET-05 | 自动缓存 | 开关自动缓存 | 状态持久化，不影响手动下载 |
| SET-06 | 启动自动播放 | 开关后刷新 | 行为符合开关 |
| SET-07 | 通知开关 | APK 内开关 | 通知状态与设置一致 |

## 通过标准

- 设置修改后刷新页面仍保持。
- 设置弹窗不被底部播放器遮挡。
