# 15 人工验证提示词

本文件用于交给其他模型执行“当前没有自动测试覆盖、需要人工或半自动验证”的项目。每段提示词都可以单独复制给模型。

## 通用前置提示词

```text
你现在是既见项目的测试执行模型。项目目录是 /Volumes/Ventoy/tools/jianyin-web-clean-public，桌面端地址是 http://127.0.0.1:5188/。

安全要求：
1. 不允许清空真实 localStorage。
2. 不允许删除真实 IndexedDB 音频。
3. 删除类测试只能使用你自己创建的隔离浏览器上下文和测试歌单。

5. 每个测试都要记录：执行步骤、实际结果、是否通过、失败截图或日志。

请先确认服务健康：curl -fsS http://127.0.0.1:5188/api/health。
```

## APK-04 到 APK-08 真机 adb 操作

```text
请验证 APK-04 到 APK-08：真机覆盖安装、签名、启动、本地播放、顶部留白。

环境：
- 项目目录：/Volumes/Ventoy/tools/jianyin-web-clean-public
- APK：android/app/build/outputs/apk/release/app-release.apk
- adb：/Volumes/Ventoy/tools/android-sdk/platform-tools/adb
- 包名：com.randerous.jianyin
- 需要 Android 真机已连接并授权 adb。

禁止事项：
1. 禁止 adb uninstall。
2. 禁止 pm clear。
3. 禁止删除 App 数据目录。
4. 只能使用 adb install -r 覆盖安装。

步骤：
1. 执行 adb devices -l，确认设备在线。
2. 安装前执行 dumpsys package com.randerous.jianyin，记录 versionName、versionCode、firstInstallTime、signatures、primaryCpuAbi。
3. 执行 adb install -r android/app/build/outputs/apk/release/app-release.apk。
4. 安装后再次执行 dumpsys package，记录同样字段。
5. 启动 App：adb shell am start -n com.randerous.jianyin/.MainActivity。
6. 通过 WebView DevTools 或页面人工操作打开“我的”。
7. 检查下载管理、本地恢复歌单是否存在。
8. 在下载管理点击一首已下载歌曲播放。
9. 验证 audio.currentSrc 为 blob: 开头，或人工确认歌曲开始播放且非远程请求。
10. 播放中切到“我的”，检查顶部无 1/4 留白。
11. 读取 DOM：.app-shell 应包含 has-mini-player，不包含 has-live-player。

通过标准：
- adb install -r 返回 Success。
- firstInstallTime 安装前后不变。
- APK 证书 SHA-256 为 09392c015136c81b1aa60be09958ba2d8218dccba822d275124f2d5dba226d92。
- primaryCpuAbi 为 arm64-v8a，secondaryCpuAbi 为 null。
- App 能启动。
- 已恢复下载能播放。
- 顶部无大留白。

输出格式：
- 设备型号/序列号：
- 安装前 package 信息：
- 安装后 package 信息：
- install -r 结果：
- 本地播放验证结果：
- 顶部留白验证结果：
- 结论：通过/失败
```
