# 01 启动与基础渲染测试

## 环境

- 桌面端：`http://127.0.0.1:5188/`
- 推荐视口：`1440x920`、`768x1024`、`390x844`

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| BOOT-01 | 首页启动 | 打开桌面端首页 | 页面标题为“既见”，首页内容可见 |
| BOOT-02 | API 健康 | 请求 `/api/health` | 返回 `ok: true` |
| BOOT-03 | 刷新恢复 | 首页、搜索、我的各刷新一次 | 页面可恢复，无白屏 |
| BOOT-04 | 多视口 | 三档视口分别打开首页 | 无横向溢出，无明显重叠 |
| BOOT-05 | 控制台错误 | 监听 `pageerror` 和 console error | 无 uncaught error |

## 通过标准

- 首屏 3 秒内可见主要内容。
- 任何失败都应有可读提示，不能静默白屏。
