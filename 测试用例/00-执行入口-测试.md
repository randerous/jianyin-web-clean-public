# 00 执行入口测试

## 环境

```bash
cd /Volumes/Ventoy/tools/jianyin-web-clean-public
npm install
```

桌面功能测试使用独立的 `5189` 端口和测试状态文件，不需要预先启动开发服务。

浏览器性能测试使用独立的 `5190` 端口和另一份测试状态文件。

## 测试方法

| ID | 动作 | 通过标准 |
|---|---|---|
| ENTRY-01 | 运行 `npm run build` | TypeScript 和 Vite build 成功 |
| ENTRY-02 | 运行 `npm run test:api` | 所有确定性 API 用例通过，且不包含真实网络测试 |
| ENTRY-03 | 运行 `npm run test:e2e` | `tests/e2e/*.e2e.ts` 全部通过，且只使用 1 worker |
| ENTRY-04 | 运行 `npm run test:perf` | `tests/perf.e2e.ts` 全部通过并生成性能报告 |
| ENTRY-05 | 运行 `npm run test:all` | build、API、功能 E2E、浏览器性能四个门禁依次通过 |
| ENTRY-06 | 按需运行 `npm run test:smoke:flac` | 独立真实网络 FLAC 搜索、解析和分段流验证通过 |

## 注意

- 功能 Playwright 使用 `5189` 和 `test-results/.jianyin-e2e-state.json`。
- 性能 Playwright 使用 `5190` 和 `test-results/.jianyin-performance-state.json`。
- 两个套件禁止并行共享状态；性能统计必须从页面可交互稳态开始。
- 如果要做真实桌面黑盒测试，先备份 `.jianyin-shared-state.json`。
- 当前状态从实际报告自动生成到 `test-results/test-status.json`，不在本文手工维护通过数量。
- E2E 和性能套件摘要位于 `test-results/reports/`，详细性能指标位于 `test-results/perf-report.json`。

## 查看当前状态

```bash
npm run test:status
cat test-results/test-status.json
```
