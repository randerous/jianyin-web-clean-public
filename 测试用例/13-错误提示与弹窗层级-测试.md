# 13 错误提示与弹窗层级测试

## 环境

- 推荐同时覆盖桌面视口 `1440x920` 和移动视口 `390x844`。
- 使用 mock 接口制造错误。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| ERR-01 | 搜索失败 | mock `/api/flac/search` 返回 500 | toast 可见，文案明确 |
| ERR-02 | 歌单导入失败 | mock playlist 返回 404/500 | 弹窗内显示错误，不新增歌单 |
| ERR-03 | 播放失败 | mock song resolve 无 URL | toast 显示无法播放原因 |
| ERR-04 | 存储失败 | mock `localStorage.setItem` throw | toast 显示存储空间不足 |
| ERR-05 | 播放器层级 | 播放中触发 toast | toast 不被 mini player 挡住 |
| ERR-06 | 搜索分页层级 | 搜索结果分页时触发 toast | toast 不被分页条挡住 |
| ERR-07 | 设置弹窗 | 播放中打开设置 | 弹窗居中/可操作，可关闭 |
| ERR-08 | 账号弹窗 | 打开账号同步并触发错误 | 错误在弹窗内可见，不贴底 |

## 通过标准

- 错误必须可读，不允许只在控制台报错。
- toast、弹窗、mini player、底部导航不能互相遮挡关键操作。
