# 12 账号同步测试

## 环境

- 使用 mock cookie 和 mock 接口。
- 不输入真实账号 cookie，除非用户明确提供测试账号。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| ACC-01 | 网易云无效 cookie | 输入 mock 无效 cookie | 显示错误，不创建假歌单 |
| ACC-02 | 网易云有效同步 | mock profile 和 playlists | 同步可播放歌单 |
| ACC-03 | Bili 无效 cookie | 输入 mock 无效 cookie | 显示错误，不泄露 cookie |
| ACC-04 | Bili 有效同步 | mock 收藏夹和音频解析 | 歌单出现，可播放 |
| ACC-05 | 退出账号 | 同步后退出 | 账号状态清除，Bili 歌单移除 |
| ACC-06 | 凭据泄露检查 | 搜 localStorage、toast、网络响应 | 不出现 cookie/token 明文 |

## 通过标准

- 失败不能生成假歌单。
- 错误文案不能包含凭据。
