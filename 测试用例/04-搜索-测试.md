# 04 搜索测试

## 环境

- 桌面端或 Playwright mock `/api/flac/search`。

## 用例

| ID | 测试点 | 方法 | 通过标准 |
|---|---|---|---|
| SEARCH-01 | 空关键词 | 搜索框空内容按 Enter | 不发搜索请求，不报错 |
| SEARCH-02 | 普通搜索 | 输入关键词搜索 | 结果列表出现歌名/歌手 |
| SEARCH-03 | 结果播放 | 点击搜索结果 | 音频开始播放，duration `> 60s` |
| SEARCH-04 | 慢快竞态 | mock 慢请求 A、快请求 B | 最终只显示 B，A 不覆盖 |
| SEARCH-05 | 清旧结果 | 搜索 A 后立刻搜索 B | 旧结果不残留 |
| SEARCH-06 | 分页层级 | 移动端搜索有分页时触发 toast | toast 不被分页条遮挡 |

## 通过标准

- 搜索失败时展示明确提示。
- 搜索结果点击播放响应应在 3 秒内有状态变化。
