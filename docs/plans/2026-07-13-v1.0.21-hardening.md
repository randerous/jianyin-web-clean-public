# v1.0.21 Reliability And Privacy Hardening Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make the confirmed settings, restore, update, synchronization, and Android network behaviors safe and effective, then publish a signed v1.0.21 release.

**Architecture:** Keep the single React application and local Node backend. Replace hidden side effects with explicit user actions: settings change the actual playback/lyric paths, restores are validated and staged before they write, and update checks only fetch metadata until a user presses an update button. Android and browser API calls stay on the local app origin.

**Tech Stack:** React + TypeScript, Express, Playwright, Node test runner, Capacitor Android/Gradle.
